# Туториал

Туториал покрывает все основные возможности FastVK шаг за шагом.

- [Первые шаги](first-steps.md) — установка, первый бот, запуск.
- [Хэндлеры](handlers.md) — `@bot.message()`, `@bot.callback()`, события группы, user long poll, startup/shutdown.
- [Фильтры](filters.md) — `Command`, `Text`, `F`, `StateFilter`, `Regexp`, `ContentType`.
- [Сообщение](message.md) — `answer()`, медиа, редактирование, закрепление.
- [Вложения](attachments.md) — типизированные фото/док/видео, фильтры по типу контента.
- [Клавиатура](keyboard.md) — `Button`, `Keyboard`, `Carousel`, inline и обычная.
- [FSM](fsm.md) — состояния, `FSMContext`, хранилища.
- [Роутеры](routers.md) — разбивка бота по файлам.
- [Middleware](middleware.md) — перехват событий, внедрение данных.
- [Планировщик](scheduler.md) — периодические и ежедневные задачи.
- [i18n](i18n.md) — JSON-каталоги и локаль пользователя.
- [Lifespan](lifespan.md) — код при старте и остановке.
- [Обработка ошибок](exceptions.md) — `@bot.exception_handler()`.
- [Тестирование](testing.md) — `MockedBot`, фабрики апдейтов, `dispatch()`.
- [Командная строка](cli.md) — `fastvk new`, `fastvk run`.

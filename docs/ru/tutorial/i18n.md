# Интернационализация (i18n)

FastVK включает небольшой переводчик на JSON-каталогах и middleware, который
определяет локаль для каждого апдейта.

## Каталоги

Создай по одному файлу `<локаль>.json` на язык — плоскую карту `{ключ: текст}`:

```
locales/
  en.json   {"hello": "Hello, {name}!", "bye": "Goodbye"}
  ru.json   {"hello": "Привет, {name}!", "bye": "Пока"}
```

## Подключение

```python
from fastvk import FastVK
from fastvk.middleware.i18n import I18n, I18nMiddleware
from fastvk.types import Message

i18n = I18n("locales", default_locale="ru")
bot = FastVK(token="vk1.a.YOUR_TOKEN", middleware=[I18nMiddleware(i18n)])


@bot.message()
async def hello(message: Message, i18n: I18n) -> None:
    await message.answer(i18n("hello", name=message.from_id))
```

`i18n("ключ", **kwargs)` ищет `ключ` в активной локали, откатывается к
`default_locale`, затем к самому ключу, после чего подставляет
плейсхолдеры через `str.format(**kwargs)`.

## Определение локали

По умолчанию middleware читает `client_info.lang_id` (у колбэков) или
`message.lang` из сырого апдейта. Переопредели своим геттером — например,
из базы данных:

```python
async def get_locale(event) -> str | None:
    user_id = getattr(event, "from_id", None) or getattr(event, "user_id", None)
    return await db.get_locale(user_id)

I18nMiddleware(i18n, locale_getter=get_locale)
```

## Вне хэндлеров

Активная локаль хранится в `ContextVar`:

```python
I18n.get_locale()          # текущая локаль
I18n.set_locale("en")      # переопределить внутри текущей задачи
i18n.gettext("hello", locale="en", name="Sam")   # явная локаль
```

Вызови `i18n.reload()`, чтобы перечитать файлы каталогов на лету.
